DAVE : Distribution-aware Attribution via ViT Gradient Decomposition

ICML Spotlight

Adam Wróbel*, Siddhartha Gairola*, Jacek Tabor, Bernt Schiele, Bartosz Zieliński, Dawid Rymarczyk

International Conference on Machine Learning (ICML), May 2026

arxiv / code / presentation / bibtex

Align Once to Explain: Feature Alignment for Scalable B-cosification of Foundational Vision Transformers

CVPR

Raphael Maser*, Siddhartha Gairola*, Sukrut Rao, Bernt Schiele

IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR), 2026

abstract / arxiv / code / project_page / bibtex

ALOE (ALign Once to Explain) is a one-time, label-free feature alignment approach that efficiently converts foundational vision models (DINOv3, SigLIP2, etc.) into inherently interpretable B-cos variants. The aligned backbone serves as a drop-in replacement across downstream tasks, is 100–1000× more data-efficient than training from scratch, and outperforms fully-supervised B-cos models (e.g., +6.6 p.p. top-1 on ImageNet for ViT-B/16) while yielding well-localized, human-interpretable explanations by design.
