# Archive

Files no longer used by the site after the October 2026 redesign, kept for reference.

- `html/index_pre-redesign.html`, `css/style_pre-redesign.css` — the previous homepage and stylesheet.
- `bib/` — the old per-paper BibTeX files (inconsistent formats). Replaced by generated `assets/bib/<bibkey>.bib`.
- `images/full_figures/` — uncropped teaser figures; the site uses the two-panel crops `images/{dave,aloe,probe}_{1,2}.jpg` made from them.
- `images/logos_old/` — raster/with-text logos; replaced by the transparent marks in `images/logos/`.
- `images/profile_photos/` — earlier profile pictures.
- `images/misc/` — figures from sections that no longer exist (GSoC, thesis thumbnail).
- `images/originals/` — full-resolution PNG/JPEG sources of the figures and project-page images; the site serves downscaled JPEG versions (Oct 2026).
